# 🎮 لعبة 2048

نسخة عربية من لعبة 2048 الشهيرة، بواجهة من اليمين لليسار.
مكتوبة بـ HTML و CSS و JavaScript فقط، بدون أي مكتبات، وتعمل بالكامل داخل المتصفح على الجوال والكمبيوتر.

**العبها مباشرة:** https://ilo0ol.github.io/game-2048/

## طريقة اللعب

- حرّك المربعات بالسحب على اللوحة، أو بالأسهم، أو بالأزرار `W A S D`.
- تتحرك كل المربعات في الاتجاه نفسه حتى تصطدم بالحافة أو بمربع آخر.
- إذا التقى مربعان بالرقم نفسه اندمجا في مربع واحد قيمته مجموعهما، وتُضاف القيمة إلى نتيجتك.
- بعد كل حركة يظهر مربع جديد في مكان فارغ عشوائي: `2` غالباً، و`4` أحياناً (احتمال 10%).
- تفوز عندما تصنع مربع `2048`، ويمكنك بعدها الاستمرار للوصول إلى رقم أعلى.
- تنتهي اللعبة إذا امتلأت اللوحة ولم يبقَ مربعان متجاوران بالرقم نفسه.

## المزايا

- تحريك سلس للمربعات مع تأثير عند ظهور مربع جديد وعند الدمج.
- عدّاد للنتيجة وأفضل نتيجة، مع ظهور النقاط المكتسبة بعد كل دمج.
- زر «تراجع» لإلغاء آخر حركة (أو `Ctrl + Z`)، ويعمل أيضاً إذا ضغطت «لعبة جديدة» بالخطأ.
- حفظ تلقائي: تُحفظ اللعبة الحالية وأفضل نتيجة في المتصفح، فتكمل من حيث توقفت.
- تصميم يناسب الجوال أولاً، ويتحوّل للوضع الداكن تلقائياً حسب إعدادات الجهاز.
- يحترم إعداد «تقليل الحركة» في النظام فيلغي التأثيرات.

## التشغيل محلياً

افتح ملف `index.html` مباشرة في المتصفح، أو شغّل خادماً محلياً بسيطاً:

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## هيكل المشروع

```
index.html   بنية الصفحة
style.css    التصميم وألوان المربعات ودعم الوضع الداكن
script.js    منطق اللعبة والتحكم بالسحب ولوحة المفاتيح والحفظ
```
